# 3D Tetris — クレーンゲーム型

クレーンゲームの筐体の中で遊ぶ3Dテトリス。上から吊られて降りてくる立体ブロックを、クレーンの移動・回転で狙いを定めて落とし、水平な一段を埋めて消す。

2Dテトリスを3Dにすると奥行きの把握が追いつかず、自動落下のままでは操作が破綻する。そこで落下の主導権をプレイヤーに渡し、「狙いを定める時間」と「落とす瞬間」を分離した。クレーンゲームという題材は、この構造をそのまま持っている。

ブロックは角丸で柔らかい質感。着地するとむにゅっと潰れ、吊られている間はぷるんと揺れる。目指す絵は「クレーンゲームの中のぬいぐるみ」。

## ゲームルール

| 項目 | 内容 |
|---|---|
| 盤面 | 4 × 4 × 8（底面16マス、高さ8段） |
| ピース | 4セルのテトラキューブ8種（平面5種 + 立体3種） |
| 落下 | 自動落下なし。任意のタイミングでドロップ |
| 制限時間 | 1手番20秒（固定）。時間切れで現在位置に強制ドロップ |
| 回転 | ワールド3軸それぞれ90度単位。全24姿勢 |
| 消去 | 水平レイヤー1層（16マス）が全埋めで消去。上の層が1段落ちる |
| スコア | 同時消去レイヤー数のみで決定（1/2/3/4層 = 100/300/700/1500） |
| 難易度変化 | なし |

## 操作（キーボードのみ）

カメラは盤面の4側面から見下ろす4視点。**入力はすべてカメラ相対**で、画面上で「右」に見える方向へ入力すると、ピースは画面上で右に動く。どの視点に切り替えてもこの関係は変わらない。

左手が「どこに置くか」、右手が「どの向きで置くか」を担当する。

| キー | 動作 |
|---|---|
| `W` `A` `S` `D` | ピースを移動（奥 / 左 / 手前 / 右） |
| `Q` `E` | カメラ切り替え（左回り / 右回り） |
| `I` `J` `K` `L` | ピースを倒す（奥 / 左 / 手前 / 右） |
| `U` `O` | ピースをひねる（Y軸回転 左 / 右） |
| `Space` | ドロップ |
| `Esc` | ポーズ |

## 技術構成

- Unity 6 / URP / Input System / UniTask
- プラットフォーム: PC（キーボードのみ）

### アセンブリ構成

```
Assets/_Project/
  Core/           ゲームロジック。MonoBehaviour も Transform も Time も使わない純粋C#
  Presentation/   描画・演出
  Input/          入力のカメラ相対変換
  App/            組み立てと進行管理
  Tests/EditMode/ Core のみを対象としたテスト
```

依存の向きは一方向で、`Core` は他のどのアセンブリも参照しない。asmdefで強制している。

**設計の要は `Core` をUnityから切り離している点。** 24姿勢の回転・着地計算・レイヤー消去は目視での検証が難しく、ここを自動テストで固められるかがプロジェクトの成否を分ける。演出を全て0秒にしてもゲームは同じ結果で最後まで進行する。

座標はセル座標（`Vector3Int`、ロジック用）とワールド座標（`Vector3`、描画用）を分離し、変換はセル → ワールドの一方向のみ。
